为什么需要图提取？

做电商运营、选品分析、素材整理时，你是否总被这些问题拖慢节奏

电商详情页的图片往往分散在主图、SKU、详情长图、场景图等各个模块， 想保存下来只能一张张右键另存，遇到懒加载和限制右键的页面更是无从下手。

图提取把「找图 → 存图 → 转格式」压缩成一次点击：自动扫描整页图片、 智能过滤干扰元素，在新页面网格化集中预览，勾选后一键批量保存为统一的 PNG 格式。

图片分散难收集

主图、细节图、长图散落在页面各处，手动翻找费时费力。

无法批量保存

右键另存一张张点，几十张图的操作重复又低效。

格式五花八门

JPG、Webp 混杂，上传或整理时还要再转一遍格式。

核心功能

从提取到保存，一张图都不用你手动操心

一键提取

自动扫描页面所有商品图，兼容 srcset、data-* 等各类懒加载写法。

智能过滤

自动排除图标、logo、占位图与小于 100×100 的干扰图片。

集中预览

新页面网格化展示全部提取结果，缩略图与尺寸信息一目了然。

自由勾选

全选、反选随心操作，已选数量实时统计，只下你想要的。

统一 PNG

JPG、Webp 自动经 canvas 转换为 PNG，格式整齐不再杂乱。

批量下载

一键保存到本地，文件名自动按 商品图_001 编号，带进度反馈。

安装步骤

无需商店上架，开发者模式 4 步完成加载

  1. 1

    下载并解压插件

    点击本页「下载插件」按钮获取压缩包，解压到电脑上的任意文件夹。

  2. 2

    打开扩展管理页

    打开 Chrome，在地址栏输入 chrome://extensions 后回车。

  3. 3

    开启开发者模式

    在扩展管理页右上角，打开「开发者模式」开关。

  4. 4

    加载插件文件夹

    点击「加载已解压的扩展程序」，选择解压后的 extension 文件夹即可。
