# 图提取 ImageGrab —— Chrome 电商图片提取下载插件

在淘宝 / 京东 / 拼多多商家版的商品详情页，一键提取页面内所有商品图片，
在新标签页集中展示、勾选，并批量下载为 PNG 格式。

## 安装（开发者模式加载）

1. 将本文件夹（`extension`）解压或复制到电脑任意位置
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
3. 打开右上角「开发者模式」开关
4. 点击左上角「加载已解压的扩展程序」，选择本文件夹（含 `manifest.json` 的目录）

## 使用

1. 打开淘宝 / 京东 / 拼多多商家版的任意商品详情页
2. 点击页面右下角悬浮的「获取图片」按钮
3. 插件自动扫描页面图片（含懒加载），随后打开「图片画廊」新标签页
4. 在画廊中勾选需要的图片（支持全选 / 反选），点击「下载选中」
5. 图片统一转换为 PNG，按 `商品图_001.png`、`商品图_002.png` … 编号
   保存到浏览器默认下载目录，底部有进度与结果反馈

## 说明

- 仅在商品详情页显示悬浮按钮，列表页 / 首页不会显示
- 自动过滤图标、logo、占位图以及小于 100×100 的图片
- 已声明图片 CDN（alicdn / 360buyimg / pddpic）的跨域权限用于 PNG 转换；
  个别无法转换的图片会自动回退为「原图直链下载」并保留原格式
- 若页面图片较多，提取和下载需要稍作等待，属于正常现象
